# Recruitment System

This is a simple **Recruitment Management System** built using **Java**. The system allows users to register as candidates or recruiters, login, and manage recruitment data. It also supports features like advanced search, login functionality, and saving/retrieving data from a file.

## Features

- **User Registration**: Users can register as candidates or recruiters.
- **Login System**: Users can log in using their email and password.
- **Advanced Search**: Recruiters can search for candidates based on various criteria.
- **Save & Load Data**: The system can save user data to a file and load it when the application restarts.

## Technologies Used

- **Java**: Main programming language.
- **Maven**: Build tool for managing dependencies and project structure.
- **File Storage**: Used to store user data.
